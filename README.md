# El Reino de la Química 3

Nueva versión RPG educativa construida desde cero para GitHub Pages.

## Objetivo visual
- Mundo 2.5D tipo RPG.
- Tres personajes seleccionables: Kimi Man, Kimi Woman y Alternative Kim.
- HUD de vida, XP, conocimiento, preguntas y monedas.
- Zonas temáticas de química.
- NPC guía, cofres y desafíos educativos.

## Controles
- WASD o flechas: mover.
- E: interactuar con NPC/cofres.
- Espacio: ataque.

## Zonas iniciales
1. Bosque de Estados de Oxidación.
2. Valle de Reacciones Químicas.
3. Lago de pH.
4. Santuario de pKa, pI y solubilidad.

Esta versión se desarrolla de forma independiente de `juego-quimica` y `juego-quimica2`.
